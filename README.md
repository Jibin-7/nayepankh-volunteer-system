# Nayepankh Volunteer Management System

### Volunteer Registration and Administrative Dashboard

A full-stack volunteer management application with a public registration form, administrator login, and dashboard for managing volunteer submissions.

[Live Application](https://nayepankh-volunteer-system-mu.vercel.app/) · [Source Code](https://github.com/Jibin-7/nayepankh-volunteer-system)

</div>

---

## Features

- **Volunteer registration:** Public form for collecting volunteer submissions.
- **Admin access:** Login page for administrative users.
- **Dashboard:** Separate route for the admin dashboard.
- **Full-stack structure:** Dedicated frontend and backend directories.

## Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React, React Router, Vite |
| Backend | Node.js, Express |
| Database | MongoDB, Mongoose |

## Repository Structure

```text
frontend/    React interface and volunteer/admin views
backend/     API server and data handling
```

## Getting Started

Install and run the frontend from the `frontend` directory using its package scripts. Install the backend dependencies from the root package configuration, configure the required MongoDB connection and environment variables, then start the API server.

## Deployment

The live application is available at [nayepankh-volunteer-system-mu.vercel.app](https://nayepankh-volunteer-system-mu.vercel.app/). Configure frontend API URLs and backend environment variables for the target deployment environment.
